KALKI · Version history (open any .html by double-clicking; runs offline in Chrome/Edge)

v0.1    First prototype: 18 camera moves, timeline, no-code + code modes, onboarding, exports
v0.2    Cinematic look: window light + sun shafts, depth of field (aperture), bloom,
        motion blur, film grain, 5 colour looks
v0.3    Realistic actors (Microsoft Rocketbox) with real idle/walk animation
        (note: textures may fail to load in some browsers - use v0.3.1)
v0.3.1  Fixed actor textures for all browsers, brighter wide shots
v0.4    Shot-list PDF export, camera sensor presets with full-frame equivalents,
        versioned project files (older files still open)
v0.4.1  Storyboard sheet PDF (frame grid with captions), per-shot notes in the PDFs and CSV,
        Windows desktop app
v0.4.2  Frame guides (thirds, safe areas, Reels/Shorts zones), built-in self-test,
        PDF text ends with "..." instead of cutting off
v0.5    Latest: actions for each actor (stand, walk, sit, talk, listen, nod, sip chai, wave,
        look around, shrug, invite to sit), plastic chair and chai glass props  << recommended

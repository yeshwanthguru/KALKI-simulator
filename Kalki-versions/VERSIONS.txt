KALKI · Version history (open any .html by double-clicking; runs offline in Chrome/Edge)

v0.1    First prototype: 18 camera moves, timeline, no-code + code modes, onboarding, exports

v0.4.2  Frame guides (thirds, safe areas, Reels/Shorts zones), built-in self-test,

v0.5    Actions for each actor (stand, walk, sit, talk, listen, nod, sip chai, wave,
        look around, shrug, invite to sit), plastic chair and chai glass props
v0.5.1  Click-to-place actors on the set view, facing control, top-down blocking diagram PDF
v0.5.2  Action lane (timed action changes inside a shot, with blending)
